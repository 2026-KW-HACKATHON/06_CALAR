# 크레딧

`users.credit`는 원 단위 정수 잔액이며 `credit_transactions`에는 충전·결제·환불 내역을
저장합니다. 모든 변경은 DB 트랜잭션으로 처리하며 중복 요청 키로 중복 지급·결제를 방지합니다.
주문 거절 시 크레딧 결제 금액을 환불합니다. 가게에서 결제하는 주문은 크레딧을 차감하지 않습니다.

개발용 충전은 `.env`에 `CALAR_DEV_CREDIT=true`를 설정하면 활성화됩니다.
`NODE_ENV=production`에서는 이 설정과 관계없이 개발용 충전을 차단합니다.
개발용 크레딧은 실제 돈의 충전이나 점주 정산을 의미하지 않습니다.

실제 결제 연동 시에는 결제사의 결제 완료를 서버에서 검증하고, 검증한 금액과
결제번호를 기준으로 `creditService.change(userId, amount, 'topup', paymentId)`를
트랜잭션 안에서 호출해야 합니다. 브라우저가 전달한 결제 성공 여부나 금액만으로 지급하면 안 됩니다.
