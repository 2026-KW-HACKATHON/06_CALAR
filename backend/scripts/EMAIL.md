# 이메일로 비밀번호 복구

회원가입 후 `/verify-email`에서 인증 메일을 요청합니다. 메일 링크를 열고
인증 완료 버튼을 누르면 `users.email_verified_at`에 인증 시각이 저장됩니다.
관리자 사용자 목록에서도 인증 시각을 확인할 수 있습니다.
이메일 인증과 사업자 승인은 별도로 관리하며 기존 계정의 로그인은 유지됩니다.
비밀번호를 잊은 경우 `/reset-password`에서 복구 메일을 요청합니다.

Gmail 시연 설정:
1. 발신 Gmail 계정에 2단계 인증을 활성화합니다.
2. Google 계정의 앱 비밀번호를 발급합니다. 일반 로그인 비밀번호를 사용하지 않습니다.
3. `backend/.env.example`을 `backend/.env`로 복사하고 발신 주소와 앱 비밀번호를 입력합니다.
4. 백엔드를 재시작합니다. `.env`는 자동으로 읽으며 Git에 커밋하지 않습니다.

`CALAR_PUBLIC_URL`은 사용자가 접속하는 프론트엔드 주소입니다. 로컬 시연은
`http://localhost:5173`, 배포 시에는 실제 HTTPS 주소로 설정합니다.
호스팅에서는 `.env` 대신 호스팅 서비스의 환경변수로 같은 값을 설정할 수 있습니다.
다른 SMTP 서비스도 호스트, 포트, 계정, 비밀번호와 발신 주소를 변경하면 됩니다.

복구 링크는 15분 후 만료되고 한 번만 사용할 수 있습니다. DB에는 토큰의 SHA-256
해시만 저장합니다. 변경 완료 시 기존 로그인 세션과 다른 복구 링크를 무효화합니다.
등록되지 않은 이메일도 같은 응답을 받으며 IP당 15분에 10회로 요청을 제한합니다.
SMTP 설정이 없으면 화면에 발송 준비가 필요하다는 안내가 표시됩니다.

https://support.google.com/accounts/answer/185833?hl=ko
