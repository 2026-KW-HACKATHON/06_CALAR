프론트의 핵심 컴포넌트를 기반으로 API명세를 작성하려고 한다.

##home

home에는 간판 찍기 버튼, 추천 음식들이 있다.
추천 음식을 받아오는 API를 만들면 될 것 같다.
요청 예시
```
POST /api {p: 0}
```
p는 purpose의 약어이다.
응답 예시   
```
200 {
count: 20,
food_ids: [12,34,56,78,91,23,45,67,89,10]
}
```   
```
500
```   
위의 경우는 서버에서 에러가 발생한 경우이다.   
음식의 id를 받아왔으니 음식의 정보를 얻어오면 될 듯하다.
요청 예시
```
POST /api {p:1, d:12}
```
d는 data의 약어이다. d로 food_id(INT32)를 넣는다. p=0에서 받아온 food_ids의 첫 번째 값이 12였으므로 12를 넣어준다.
