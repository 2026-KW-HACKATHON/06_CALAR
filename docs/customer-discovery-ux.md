# 고객 탐색 UI/UX

고객 웹 세션은 `calar_customer_session` HttpOnly 쿠키를 기준으로 인증한다. 새로고침 시 쿠키가 있으면 동일 고객을 유지한다. 쿠키가 삭제되거나 만료되면 새 고객 계정을 생성하며 브라우저에 남아 있는 Bearer 토큰으로 이전 주문을 복원하지 않는다. 주문·내 정보 조회 전에 세션을 확인한다. 고객 ID가 바뀌면 찜·동의 캐시·지역·추천 숨김·목표 등 고객 브라우저 설정을 초기화한다. 이전 주문은 점주 관리와 이력 보존을 위해 DB에 유지되며 새 고객은 이전 고객 주문에 접근할 수 없다. IP로 계정을 복원하지 않는다. 점주·관리자 및 기존 네이티브 API의 Bearer 인증은 유지한다.

위치정보 동의는 DB를 기준으로 복원한다. `GET /api/auth/location-consent`는 `accepted: null`(미선택), `true`(동의), `false`(거절/철회)와 변경 시각을 반환한다. 인증된 본인만 조회·변경할 수 있으며 변경 요청은 boolean만 허용한다. 고객 세션 복원 응답에도 동의 상태를 제공한다. 브라우저 캐시는 위치 권한 허용의 근거로 사용하지 않는다. DB 조회 실패 시 실제 위치 요청을 실행하지 않고 재시도를 안내한다. 설정의 위치정보 이용 동의에서 철회하면 실행 중 위치를 폐기하고 지역 기반 탐색으로 전환한다.

## 홈 화면 추가 구성

- 프로모션 안내 이미지: 화면 높이 약 1/3(200~300px), 좌우 스와이프·이전/다음·선택 점 지원. 6초 자동 전환, 포커스·호버·비활성 탭·동작 줄이기 설정에서는 자동 전환을 억제한다. 현재 이미지는 실제 할인 광고가 아닌 서비스 안내 예시라고 표시한다.
- 마일리지: `calar.mileageGoal`에 브라우저별 목표 저장. 적립 기준 미정이므로 실제 잔액·적립량·달성률을 생성하지 않고 준비 중 상태를 표시한다. 목표는 1~10,000,000 정수만 허용한다.
- 카드지갑: 최근 주문은 고객 본인의 `/api/orders/mine` 데이터만 표시한다. 미로그인·내역 없음·조회 오류에서도 주문 내역 화면에 진입할 수 있다. 내 쿠폰은 현재 가게에서 제공하는 혜택 목록이며 별도 개인 발급 쿠폰을 의미하지 않는다.
- 동네 가게: 개별 가게 슬라이드와 추천 팝업을 제공한다. 동의 선택 완료 후 실행 중 첫 홈 방문에서 한 번 팝업을 표시하고, ‘추천 보기’로 다시 열 수 있다. 닫기·Esc·기본 dialog 포커스 처리 지원. 현재 신규·저방문 추천을 사용하며 `recommendationPolicy` 어댑터를 회의 후 결정된 알고리즘으로 교체한다. 인기·급상승 데이터가 없으므로 실제 인기 순위로 표현하지 않는다.
- 헤더: 스크롤 중 상단 고정. 역할 선택 바로 왼쪽 빈 하트로 찜 목록에 진입한다. 가게 상세에서 찜 등록·해제; `calar.favorites`에 가게 ID를 저장한다. 저장 실패 안내, 빈 목록 안내, 조회 오류 재시도 제공. 삭제된 가게는 찜 목록에서 표시하지 않는다.
- 점주 소개 사진: 승인된 해당 가게 점주만 1장 등록·교체·삭제 가능. 일반 매장 갤러리와 독립 저장한다. 기존 사진 업로드와 동일한 포맷·크기·해상도·디코딩 검증을 적용하며 고객 상세에서 표시한다.
- 위치 동의: 점주 가입 시 선택 체크, 고객 자동 계정 시작 시 동의/거절 선택. `location_consents`에는 동의 여부와 변경 시각만 저장한다. 좌표는 DB에 저장하지 않는다. 위치 버튼에서 동의 선택을 바꿀 수 있으며 이후 기기 권한 요청이 별도로 진행된다. 동의 거절에도 이용 가능하다.

퍼스널 컬러는 기존 감빛 주황 `#B4400F`를 사용한다. 주요 행동, 선택 탭, 중앙 촬영 버튼, 인식 진행에 적용한다. 기본 탭은 중립색이며 아이콘·텍스트·선택 배경·굵기로 상태를 함께 표현한다. 최소 글자 크기 16px, 터치 영역 48px 이상, 촬영 원 64px, 키보드 포커스 표시를 제공한다.

대표 메뉴는 첫 메뉴이며, 없으면 ‘준비 중’을 표시한다. 추천 카드에는 대표 사진·이름·거리·영업 상태·대표 메뉴·추천 이유를 함께 표시한다. 위치/지역 선택 없이도 추천·가게 탐색은 이용할 수 있다. 위치 없는 매장은 지역 반경 검색에서 제외하며 전체 목록에서는 확인 가능하다.

카메라는 웹에서 별도 자동 기기 실행을 강제하지 않는다. 중앙 탭으로 간판 촬영 화면을 열고 ‘사진 찍기’를 누르면 기기의 촬영/사진 선택 기능이 열린다. 현재 서버가 수치 신뢰도를 제공하지 않으므로 모든 인식 결과에 고객 확인을 적용한다.

지역 목록은 `discoveryPreferences.js`의 `REGIONS`로 확장한다. 로컬 저장 항목은 이 브라우저에 한정되며 고객 계정 간 서버 동기화는 하지 않는다. 설정 세부 메뉴는 결정 후 추가한다.
